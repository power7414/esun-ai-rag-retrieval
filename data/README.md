# data/ — put the competition data here (not included in this repository)

The questions, answers and reference documents were **provided by the competition organizer
(E.SUN Bank) to participants and may not be redistributed**, so they are not in this repository.
Everything under `data/` except this file is ignored by git.

Place the official preliminary-round files exactly like this (same structure as the organizer's
release):

```text
data/
├── README.md                                  (this file, tracked)
├── dataset/
│   └── preliminary/
│       ├── questions_example.json             # 150 example questions (50 faq / 50 insurance / 50 finance)
│       └── ground_truths_example.json         # answers for the 150 example questions
├── reference/
│   ├── faq/pid_map_content.json               # FAQ entries keyed by pid
│   ├── finance/0.pdf … 1034.pdf               # 1,035 listed-company financial reports
│   └── insurance/1.pdf … 643.pdf              # 643 insurance policy documents
└── processed/                                 # generated by the scripts, never committed
    ├── finance_content.json                   # scripts/build_finance_raw.py   (needed for the 88.67% run)
    ├── finance_failed_files.json              # scripts/build_finance_raw.py   (87 scanned PDFs without text)
    ├── processed_finance_data.json            # scripts/build_processed_corpus.py (alternative methods only)
    ├── processed_insurance_data.json          # scripts/build_processed_corpus.py (alternative methods only)
    └── unified_cache/                         # PDF-text cache written by scripts/unified_pipeline.py
```
