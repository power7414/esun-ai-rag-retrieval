# 消融實驗與放棄的做法（Ablation Study）

> 2026-11-07 依實測重寫。所有數字都是在官方初賽範例 150 題（FAQ／保險／金融各 50 題）上重新執行程式得到的
> Precision@1。
> 注意：所有變體都在同一份 150 題上比較，沒有獨立 held-out 集，存在選擇偏差。

---

## 1. 金融：短問句 vs 長財報（本專案最大瓶頸）

官方 baseline（jieba + BM25）在金融只有 44%。下表為金融 50 題的實測（BM25 0.4／向量 0.6 固定權重，未調參）：

| 變體 | BM25 文字 | 向量 | 金融 P@1 |
| :--- | :--- | :--- | :---: |
| 官方 baseline | 官方前處理 | — | 44% |
| 整篇向量（Q2A，只取前 512 token） | — | 原文截斷 | 66% |
| 同上，改用已斷詞的 processed 文字 | — | processed 截斷 | 52% |
| 切片向量單獨（384 字窗口、重疊 128、max-pooling） | — | processed 切片 | 46% |
| 切片向量單獨 | — | **原文**切片 | 76% |
| 2024-11-09 TF-IDF + pdfplumber 表格抽取 | 文字＋表格 | — | 68% |
| processed 文字 BM25 + processed 切片 hybrid（`chunk_hybrid`） | processed／jieba | processed 切片 | 70% |
| 原文 BM25（無字典）+ 原文切片 hybrid | 原文／jieba | 原文切片 | 78% |
| **原文字典 BM25 + 原文切片 hybrid（`dict_hybrid`，採用）** | 原文／jieba＋79 詞字典 | 原文切片 | **80%** |
| 同上 + 11/08 時間處理器 | 原文＋時間正規化 | 原文＋時間正規化切片 | 74% |
| 字典 BM25 單獨 | 原文／字典 | — | 50% |
| 截斷向量取代切片（其餘同 `dict_hybrid`） | 原文／字典 | 原文截斷 | 72% |

結論：

- **影響最大的是文字版本**：舊的 processed 文字已斷詞、去停用詞，連「年／月」都被刪掉（例如 `民國 112 1 1 日至 9`），
  切片向量只剩 46%；改用原文（只去空白、頁碼、`$`）就有 76%。
- **切片 + BM25 融合**再把金融推到 78～80%；切片比截斷好（80% vs 72%）。
- **金融字典只多答對 1 題**（78% → 80%）。字典有 10 個詞含全形括號或頓號，jieba 會先在這些符號切開，實際上保護不到。
  舊文件舉的「資本適足率」例子不在 11/08 字典內，也沒有出現在這 50 題與其候選文件中。
- **時間正規化沒有幫助**：50 題的 query 都寫西元（如「2023年第1季」），時間處理器只改得到文件端的民國日期，hybrid 反而降到 74%。
- 在同一份 50 題上掃描 BM25 權重：`dict_hybrid` 在 w = 0.1～0.4 都是 80～82%，0.4 不是剛好挑到的尖峰；
  但掃描結果本身不能拿來當成績（會過度擬合）。

## 2. FAQ：問對問（Q2Q）

FAQ 的候選是官方 JSON 內的問答。用 Conan-embedding-v1 比對「使用者問題 vs FAQ 問句」（不比對答案），FAQ 從 baseline 的 90%
提升到 **96%**。11/09 的 TF-IDF 整合版 FAQ 為 92%。

## 3. 保險：條款切片向量 vs TF-IDF

| 做法 | 保險 P@1 |
| :--- | :---: |
| 官方 baseline BM25 | 80% |
| 條款（Article）切片 + Conan 向量（11/06） | 88% |
| pdfplumber 純文字 + `jieba.cut_for_search` + TF-IDF（11/09，採用） | **90%** |

## 4. 無法驗證、已從文件移除的說法

| 舊說法 | 現況 |
| :--- | :--- |
| 11/02 直接 Q2A 向量檢索金融 12%、整體 60.67% | 原程式需要本機沒有的模型、無 P@1 紀錄；用同一 Conan 模型實測整篇 Q2A 為 66%（斷詞文字 52%）。 |
| BiLSTM / DSSM 雙塔模型金融 0% | 早期的 BiLSTM/DSSM 測試程式只會印出寫死的 0%（已自 repo 移除）；11/09 的 DSSM 程式需要 `bert-base-chinese` 並現場訓練，未重跑。 |
| 全面 Tesseract OCR 金融 48%、整體 72.67%，「資本適足率 → 資木適足率」錯字 | 找不到對應程式與紀錄。87 份金融 PDF 是掃描檔（沒有文字層），目前的 pipeline 直接略過它們。 |
| 最佳組合 FAQ 96／保險 88／金融 80／整體 88.00% | 三個數字取自不同版本，沒有被同一支程式一起跑過。單一 pipeline 實測為 96／90／80／**88.67%**。 |
